# Проект: Кибербезопасность в современном мире

## 📋 Описание
Интерактивная веб-презентация на тему кибербезопасности, созданная в рамках школьного проекта.

## 🎯 Цель проекта
Изучить основные угрозы в цифровом пространстве и научиться правилам безопасного поведения в интернете.

## 🚀 Как запустить
1. Откройте файл `index.html` в любом современном браузере
2. Используйте:
   - Стрелки ← → на клавиатуре
   - Кнопки навигации на экране
   - Цифры 1-0 для быстрого перехода к слайдам

## 📁 Структура проекта
- `index.html` - главный файл презентации
- `style.css` - стили оформления
- `script.js` - навигация и интерактивность
- `presentation.pptx` - классическая презентация (опционально)
- `assets/` - дополнительные материалы

## 📊 Содержание
1. Титульный слайд
2. Актуальность темы
3. Основные киберугрозы
4. Цели злоумышленников
5. Пример атаки
6. Правила защиты
7. Действия при взломе
8. Профессии в сфере
9. Итоги проекта
10. Заключение
